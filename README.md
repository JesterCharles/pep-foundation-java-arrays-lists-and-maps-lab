# Arrays, Lists and Maps — Code lab

Build a shop's stockroom lookup tool: start from parallel arrays, move to an `ArrayList`, index it with a `HashMap`, and finish with linear and binary search.

- **Edit:** `src/main/java/exercise/Inventory.java`. Each task is marked `TODO`.
- **Run the tests:** **Run Tests** in Exa Studio, or `mvn test` with JDK 17 and Maven. All 7 visible tests fail at first; every message starts with `Task N:`.
- **Done** when every visible test passes. **Submit** also runs held-out tests you can't see.
